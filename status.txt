WHAT CHANGED (6 commits tonight, none pushed)

1. THE NORMALIZATION LAYER (d063cfe). detect() now runs over a normalized view of the text
   and maps every candidate back to ORIGINAL offsets through an index map. Invisible
   characters deleted, homoglyphs folded, whitespace runs collapsed, NFD recomposed.
   WHY IT COULD NOT BE ONE LINE LIKE THE NBSP FIX: a 1:1 substitution preserves every
   offset, and both writers CUT THE DOCUMENT at those offsets. Deleting a character shifts
   every later offset, so the same trick on a zero-width space would not mislabel the
   output, it would CORRUPT it. Six mutation classes closed at once.
   Two things are deliberately NOT folded — CASE (some detectors use capitalisation as
   their only evidence; folding it would turn every capitalized-token rule into a
   match-everything rule) and DIACRITICS (folding č→c silently widens every Slovak-word
   pattern at once). Both are being fixed per anchor site instead.
2. ULICA COVERAGE (ed6fee8). 90 seeded occurrences. Anchored nominative shapes score 1.000;
   the declined form scores 0.000, and that is a real gap, not a fixture bug — a Slovak
   street name that is an adjective declines adjectivally (Hlavná → Hlavnej), and the shared
   stemmer deliberately excludes that ending to keep the surname-vs-adjective discriminator
   working. The fix belongs in the gazetteer, not the stemmer. Amendment 12.
3. DETECTOR ISOLATION (26e23d9). Every detector runs in a guard; one that raises loses its
   own candidates for that unit and nothing else. It is REPORTED, not swallowed — a warning
   block above the report tables and a red banner in the GUI, because a detector that
   silently stops producing rows is indistinguishable from a clean document. Fuzzed with
   control characters, format characters, other-script digits and lone surrogates: zero
   exceptions. This fired for real within the hour, on a detector another round was
   mid-refactor on — the app degraded with a warning instead of crashing.
4. BUNDLED-DATA SELF-CHECK (389bfb3). The .exe now REFUSES TO SCAN if the gazetteer data
   did not make it into the build, instead of starting normally and silently not redacting
   any place name or surname. Emptiness is checked, not just existence. Tested by simulating
   the frozen layout, which is the code path the suite otherwise never runs.
5. PHASE E GATES (34bfa7c). Per-type precision (report only — the governing rule is recall
   over precision, and an invented threshold here would start trading away the thing the
   tool exists for), cross-format consistency (gated), perf (report only).
